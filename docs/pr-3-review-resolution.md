# PR #3 review resolution

Reviewed the five inline threads and all 22 findings in the Codelean report for commit `a4ef8d11a84f`. The following dispositions use the complete code path and current provider documentation, including helpers omitted from individual model batches.

| Finding                                                         | Resolution                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local setup enables billing without credentials                 | README explicitly sets `BILLING_ENABLED=false` for credential-free local exploration. Production enforcement remains on by default.                                                                                                                                                                                                                                                           |
| Worker receives Creem webhook secret                            | Secret moved from the shared environment anchor to the web service only.                                                                                                                                                                                                                                                                                                                      |
| One workspace can exhaust shared inference                      | Documented shared-pool exhaustion, monitoring and optional workspace limits; caps remain unset by default as requested.                                                                                                                                                                                                                                                                       |
| Protected owner identity cannot be revoked                      | Documented account protection, incident recovery, session revocation and reviewed immutable-ID transfer. Product-console revocation remains prohibited by design.                                                                                                                                                                                                                             |
| Local filesystem documentation links                            | Converted to repository-relative links. Historical code-review observations remain identified as proposal context.                                                                                                                                                                                                                                                                            |
| Setup live-mode guard                                           | Applying setup now requires an explicit test/live mode; live writes also require `--live`. Previously an unset mode selected the test API, so it did not silently write to live.                                                                                                                                                                                                              |
| Bigint migration rewrites/locks runs                            | Documented maintenance-window and writer-stop requirements. Kept the required widening conversion and existing migration history.                                                                                                                                                                                                                                                             |
| Missing model usage foreign-key index                           | Migration 006 indexes `model_usage.attempt_id`, creation time, and `billing_attempts.run_id`.                                                                                                                                                                                                                                                                                                 |
| Billing page duplicates allowance/rate values                   | Rendering and thresholds now derive from pricing constants; protected owner workspaces show no plan repository cap.                                                                                                                                                                                                                                                                           |
| Retry enqueue race (reported twice, including security finding) | The existing `assertReviewAccess` acquires the workspace billing row with `FOR UPDATE`, shared with webhook enqueue. Added a real concurrent database test: two retries at nine queued runs permit one enqueue and stop at ten.                                                                                                                                                               |
| Queue check rejects ineligible retry targets                    | Check target eligibility before counting queue slots; stale forms for already queued/completed runs do not fail because the queue is full.                                                                                                                                                                                                                                                    |
| Cancellation survives transaction rollback                      | Commit a durable grant intent and hold before contacting Creem. Finalize free access and audit atomically after confirmation. A regression test forces final-commit failure after cancellation and then resumes without another cancellation.                                                                                                                                                 |
| Network calls hold grant database locks                         | Cancellation and verification now run outside transactions; durable pending state blocks conflicting billing work and is recoverable through reconciliation.                                                                                                                                                                                                                                  |
| Super-admin N+1 billing reads                                   | Fetch all displayed billing accounts with one bulk initialization and one projection query.                                                                                                                                                                                                                                                                                                   |
| Pending checkout never expires                                  | Fetch and validate the existing checkout binding. Replace only provider-confirmed expired sessions, retaining the original record. Concurrent clicks reuse the replacement. Reconciliation also marks confirmed expiry.                                                                                                                                                                       |
| Checkout URL normalized twice                                   | Retained URL allowlist validation when reading stored URLs. Validation is idempotent, rejects off-provider destinations and has no payment side effect; no bug demonstrated.                                                                                                                                                                                                                  |
| Old subscription events replace newer subscriptions             | Preserve known subscription IDs and ignore updates for replaced subscriptions, including later cancellation revisions. Compare revision timestamps before replacement.                                                                                                                                                                                                                        |
| Dollar conversion duplicates rate                               | Derive conversion from `pricing.tokensPerCent`.                                                                                                                                                                                                                                                                                                                                               |
| Alleged 100× overage price                                      | Not applicable: Creem's `usage_prices.unit_price` uses minor currency units. `0.00005` cents/token × 1,000,000 / 100 = **$0.50**. Derive it from the shared pricing constant and explicitly test the dollar conversion.                                                                                                                                                                       |
| Global reservation lock and aggregate                           | Retain the short transaction lock for correct shared-quota reservation in this single-worker, five-call-concurrency release. Added the date/attempt indexes. An O(1) counter would add reconciliation state; no measured bottleneck justifies that complexity yet.                                                                                                                            |
| Ignored webhooks acquire billing lock                           | Filter irrelevant actions and draft/closed PRs before billing lookup.                                                                                                                                                                                                                                                                                                                         |
| Queue-limit webhook reports queued                              | Return `queue full` after marking a newly received run paused by the cap.                                                                                                                                                                                                                                                                                                                     |
| Failed provider responses allegedly charged                     | Not applicable: usage capture records real provider cost, while `finishModelCall` marks failed/unknown calls and `saveReviewResult` excludes failed calls and absorbs unknown usage. Failed attempts never settle customer charges. Moving capture after validation would conceal consumed provider capacity. Existing integration tests cover failure/unknown usage and resumed-run billing. |

Provider references: [product schema](https://docs.creem.io/api-reference/endpoint/create-product), including the expanded `usage_prices.unit_price` definition; [checkout lifecycle](https://docs.creem.io/api-reference/endpoint/get-checkout). Provider mode, product pricing and a sandbox renewal invoice must still be verified before live billing is enabled; no live Creem credentials or products were changed during this review.

The PR also includes the subsequent checkpoint/retry improvements, atomic checkpoint cleanup, separate fallback timeouts, protected-owner repository exemption and inline repository billing notices. Validation: full PostgreSQL-backed application suite, scanner tests, TypeScript checks and production build.
